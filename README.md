# HelpDesk Lite

### Um sistema básico de chamados, criado para estudo e prática na linguagem Python. O projeto tem como objetivo aplicar conhecimentos teóricos na prática.
### O HelpDesk Lite simula o gerenciamento de chamados de suporte técnico. Ele utiliza as quatro operações CRUD (Create, Read, Update e Delete) que são as operações básicas para Criar, Ler, Atualizar e Excluir dados. O sistema permite cadastrar um chamado, listar os chamados existentes, atualizar a prioridade e excluir um chamado.

## Funcionalidades

- Cadastro de chamados.
- Listagem de chamados.
- Atualização de prioridade.
- Exclusão de chamados.
- Validação de campos obrigatórios.
- Validação de IDs dos chamados e prioridades.

## Tecnologias utilizadas

- Python.
- Git.
- GitHub.

## Como executar o projeto:

 É necessário ter o Python instalado.

- Clonar o repositório
```bash
git clone https://github.com/kevinbxp/helpdesk-lite.git
```

- Entrar na pasta do projeto
```bash
cd helpdesk-lite
```

- Executar o projeto
```bash
python app.py
```
